## 🧩 About

**Remnant 2 Hack Menu** is a curated list of Remnant 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot markers, map viewer
- **Quality-of-Life Helpers** — inventory catalog, build notes, config presets
- **Research Notes** — boss routes and setup notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Boss Route Notes — review encounter layouts from any checkpoint
- Damage Tracker — visualize incoming and outgoing hit values
- Replay Notes — record and review combat runs
- Playback Speed — adjust review playback for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse gear, rings, amulets, and mods
- Loot Marker Notes — organize world drop locations
- Map Viewer — improved world map visibility

### Aimbot
- Build Preset Notes — segment study on any archetype
- Trait Planner — plan trait point allocation in the editor
- Co-op Notes — chain support roles in the planner
